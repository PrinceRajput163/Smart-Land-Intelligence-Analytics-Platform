# Instructions for AI Assistant

**CRITICAL RULE:**
After *every* code modification, tool usage, or prompt response, you MUST automatically update `PROGRESS.md`.

Specifically, you must:
1. Mark finished tasks as `[x]` in the "Completed" section for the relevant teammate.
2. Update the "Active" task status or move items from "Next Up".
3. Add a new entry to the "Live Activity Log" with the current timestamp and a brief, precise description of the latest changes.
4. Never skip this step; project synchronization relies on it.
